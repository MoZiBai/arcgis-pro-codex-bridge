# v0.30.0 — 项目创建与制图体验改进

Windows x64 · ArcGIS Pro 3.6

## 中文

- 支持直接创建空白项目，或从模板创建新项目，并初始化地图与布局。
- 原生图例支持图层筛选、排序和显示项设置。
- 新增基础布局检查及导出前验证。
- 新增任务进度、历史与取消功能，改进连接诊断。

升级后请重启 MCP 客户端和 ArcGIS Pro，runtime 与 Add-in 需配套更新。

布局检查仍为试验功能，部分文字和刻度可能误报，导出前请检查预览。

## English

- Create blank projects or initialize new projects from templates.
- Filter, reorder and customize native legend items.
- Check basic layout issues before export.
- Track and cancel tasks, view job history, and diagnose connection problems.

Update the runtime and Add-in together, then restart your MCP client and ArcGIS Pro.

Layout checks are experimental and may flag text or ticks incorrectly; review the preview before export.
